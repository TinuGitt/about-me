# The Tinu Show: Animated Cartoon Theatre Experience ★

A theatrical, campy, cartoonish, auto-flowing "About Me" showcase featuring **Tinujungshi** (@bihgrandson).

## Live Page
Deployed on GitHub Pages:
**[https://tinugitt.github.io/about-me/](https://tinugitt.github.io/about-me/)**

## Highlights
- **Pure Theatre & Cartoon Camp:** Proscenium arch, scalloped valance, marquee lightbulbs, moving stage spotlights, and footlights.
- **Auto-Flowing Story:** Sits back and plays scene by scene automatically (or jump with scene pills & director controls).
- **The Six Acts:** Timeline of personal milestones from age 12 to 16+.
- **Real Visuals:** Unconventional makeup, theatre kid energy, and creative computing.
- **Soundtrack:** Features *Pink Pony Club* by Chappell Roan.
